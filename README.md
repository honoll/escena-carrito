# Escena del carrito — vista previa de diseño

Vista previa de una propuesta de diseño para el inicio de un sitio web. **No es el sitio
oficial de ningún negocio** ni está publicada como tal: el pasillo, los productos y las
promociones son de muestra.

- La escena: `index.html` (con `?medir` muestra cuadros por segundo al hacer scroll).
- Página de control del medidor, sin escena: `control/`.
